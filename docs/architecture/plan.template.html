Bound concurrency and retries. A job owns its processes, streams, and temporary files; cancellation closes their scope.

The coding standard

Small functions.
Visible contracts.

  1. Decode at entry

    Schema.decodeUnknownEffect turns untrusted input into a checked command.

  2. Name the operation

    Effect.fn keeps the use case readable and gives tracing a stable name.

  3. Ask for a capability

    The service exposes its success and expected failure. Tests supply a fake Layer.

  4. Run at the boundary

    One session-owned Atom registry and runtime; request-owned SSR identity; one scoped worker entry point.

Lifecycle matters

Save drafts through an Effect IndexedDB adapter with visible save status. Tear down the old session on logout. Router URLs own shareable filters; Convex owns durable records. A command acknowledgement and a completed render are separate states.

Execution and recovery

Fibers execute. Convex remembers.

Persist requests, leases, cancellation, and publication intents. Retries must survive a process restart without changing the meaning of the request.

  1. RequestAuthorize + validate base version + deduplicate + enqueue, in one mutation.
  2. CommitCheck base version, cancellation, lease expiry, and attempt token before advancing the visible revision.
  3. PublishWrite an already committed revision to a new filename. Verify the hash on replay; never replace conflicting bytes.

Atom is the reactive UI layer. A single Confect WebSocket client supplies live data and typed commands. The checked Atom adapter shared subscriptions, recovered after typed errors, and disposed resources in isolated registry tests. The app now waits for local authentication before mounting its live catalog, comment, and job streams.

The review loop

From a file to its next revision

Your comments stay with the version you reviewed. A correction creates a new document and a new preview.

Choose the right source

Open an indexed company or project file. Preview a specific version, check its source details, and keep the original within reach.

DOCX

Word documents

PDF previews from local conversion. Comments stay with the file version; supported body text can be revised with one exact replacement.

XLSX

Excel workbooks

A bounded read-only sheet grid with cached formula values labeled. Cell-range annotations and recalculation remain future work.

PDF

PDF files

Page navigation and text selection where available, with comments tied to the source revision.

PPTX

PowerPoint decks

Slides converted to a PDF preview. Source downloads and versioned comments work; slide-aware editing remains future work.

Exact-text revisions support DOCX, TXT, and Markdown. They do not edit arbitrary Office layouts or interpret natural-language comments. New report/invoice generation is still planned.
